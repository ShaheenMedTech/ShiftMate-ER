# Code of Conduct

## Our Commitment

ShiftMate ER is intended to be a respectful, professional, and collaborative open-source project.

Everyone participating in the project is expected to help maintain an environment that is welcoming, constructive, and safe for contributors regardless of background, experience level, profession, identity, or location.

## Expected Behavior

Contributors should:

- Communicate respectfully and professionally
- Critique ideas and code rather than people
- Give and receive technical feedback constructively
- Respect privacy, confidentiality, and security boundaries
- Use synthetic data when discussing clinical workflows
- Avoid overstating clinical validation or authority
- Follow the repository's security and contribution guidance
- Help keep discussions relevant and useful

## Unacceptable Behavior

The following are not acceptable:

- Harassment, intimidation, personal attacks, or discriminatory conduct
- Publishing another person's private information without permission
- Sharing real patient information, protected health information, credentials, secrets, or confidential institutional data
- Knowingly posting malicious code or exploit details in a public channel when responsible disclosure is appropriate
- Repeated disruption, spam, or bad-faith participation

## Clinical and Privacy Context

Because ShiftMate ER deals with healthcare workflow concepts, contributors must take particular care not to expose real clinical data or imply that unvalidated functionality is suitable for production clinical use.

Security and privacy concerns should be handled according to [SECURITY.md](SECURITY.md).

## Enforcement

Project maintainers may edit, hide, or remove contributions that violate this Code of Conduct and may temporarily or permanently restrict participation when necessary to protect the project or its community.

Concerns about conduct should be raised privately with the project maintainer whenever possible. Do not include sensitive personal, patient, credential, or vulnerability information in a public issue.

## Scope

This Code of Conduct applies to project spaces, including issues, pull requests, discussions, reviews, and other collaboration channels associated with ShiftMate ER.
